# Bayer Leverkusen 2023/24 Soccer Analytics

Exploratory soccer analytics project using StatsBomb Open Data.

## Project Goals

This project will explore:

- shot maps
- heat maps
- passing maps
- passing networks
- player metrics
- radar charts
- ball progression
- defensive analysis
- StatsBomb 360 spatial analysis
- Voronoi diagrams
- expected threat and possession value
